磁吸自拍监控屏
R600mini

Lemorele Selfie Monitor Screen · Phone Vlog Accessory

这是一个只有巴掌大的产品，却解决自拍时"看不见自己"的经典痛点。整套视觉围绕一件事展开： 把"磁吸、预览、遥控、生态"四个功能点，翻译成一条"被看见的拍摄节奏"——装上、看见、确认、走远、带走。 主副图负责讲清楚，A+ 图负责讲动人，手机端负责在窄幅里讲得更快。

Creative Logic

把"看不见自己"的痛点，
转成一套"被看见"的拍摄节奏。

自拍屏的功能点很碎：磁吸、屏幕、蓝牙、APP、对焦、像素对比。直接罗列卖点只会变成参数墙。 所以整套图先定叙事主线，再让每张图只承担叙事中的一步。

01 / Rhythm

每张图只讲节奏里的一步

装上 → 看见 → 确认画质 → 走远拍摄 → 收进口袋。九张主副图按使用时间线排列，观者顺着翻，就像替用户预演了一次完整拍摄。

02 / Scale

产品小，主体感不能小

R600mini 在画面里物理占比很小，因此所有构图都用手机背板、手掌、自拍杆等"参照物"放大它的存在感，让它始终是视线的第一落点。

03 / System

三层交付，一个视觉系统

主副图（讲清功能）→ 高级 A+（讲透场景）→ 手机端 A+（窄幅重排）。同一套蓝白主色与人物光影语言贯穿三层，保证详情页任何位置都能认出这是同一款产品。

Listing Images · 主副图 01–09

从磁吸一秒，到装进口袋。

主副图按"使用时间线"排序：前两张立产品识别，中间六张逐个拆解功能，最后一张用包装收束购买决策。

Opening · 建立识别

先让产品在两秒内被记住。

前两张主图不讲故事，只回答三个问题：这是什么、装在哪、屏幕里是什么。磁吸关系与实时画面同时出现，构成产品最核心的记忆点。

Premium A+ · 桌面端

A+ 不是主副图的重复，
而是把它放进生活里。

主副图回答"它是什么、有什么功能"；A+ 页面回答"它出现在什么样的生活里"。 头图先立气质，中段用功能矩阵承参数，后半段全部交给真实使用场景——街头、海边、美妆桌、音乐节。

Mobile A+ · 手机端

同一套系统，在窄幅里换一种讲法。

手机端不是桌面端的等比缩小：单屏信息量减半、主体比例放大、文案竖向堆叠。 十张竖图让每一次滑动只做一个决定——继续往下看。

Methodology

从参考到自己的方法论。

这套图的底层方法，是把优秀作品集里"生活方式叙事"的思路，迁移到电商详情页的交付语境里，并长出自己的四步工作法。

  1. 先定一条时间线叙事

    不按功能列表排图，而是按用户的真实使用顺序排图：装上、看见、确认、走远、带走。功能只是时间线上的站点。

  2. 一图一卖点一场景

    每张图只允许讲一件事，且必须发生在具体场景里。参数自己不会说话，是草原、街头和化妆桌替它开口。

  3. 用参照物撑起小产品

    小配件最怕在画面里失重。手掌、手机背板、自拍杆都是刻意安排的比例参照，让小产品始终握有第一视线。

  4. 三层交付，一个系统

    主副图讲清楚，A+ 讲动人，手机端讲得更快。主色、人物光影、信息卡片样式三层贯通，形成可复用的产品视觉模板。
