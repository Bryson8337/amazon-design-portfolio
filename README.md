# 邹林清｜亚马逊电商设计师作品集

这是一个无需安装依赖即可浏览的中文静态作品集网站。网站包含响应式首页、作品分类、重点案例页、大图浏览和本地可视化编辑器。

## 快速打开

双击 `打开网站.bat`，或直接双击 `index.html`。

正常打开时只显示作品集，不会出现编辑工具，适合交给 HR 浏览。

## 进入编辑模式

可以使用以下任意方式：

1. 双击 `编辑网站.bat`。
2. 打开网站后按 `Ctrl + Shift + E`；Mac 使用 `Command + Shift + E`。
3. 在网址末尾添加 `?edit=1`，例如 `index.html?edit=1`。

进入后，右下角会出现“编辑作品集”按钮。

## 可以编辑的内容

- 直接点击带虚线边框的文字进行修改。
- 点击文字后，使用浮动工具条调整字号、字间距和行高。
- 点击图片选择卡片，调整占位符高度、宽度以及图片裁切位置。
- 点击“上传替换”或编辑面板中的按钮替换图片。
- 在作品卡片上拖拽，可调整展示顺序。
- 可添加、复制或删除“作品档案”中的作品。
- 全局调整图片间距、文字与图片间距和图片圆角。
- 支持撤销近期操作、恢复默认、导出配置和导入配置。

## 保存与备份

修改会自动保存在当前浏览器中，不会改动 `作品图` 文件夹中的原图。

浏览器本地数据不会自动同步到其他电脑。完成修改后，请点击编辑器中的“导出配置”保存 JSON 备份；换浏览器或换电脑后，使用“导入配置”恢复。

上传大量高清图片时建议先适当压缩，避免浏览器本地空间不足。

## 主要文件

- `index.html`：首页、作品筛选、能力和联系方式。
- `css/style.css`：全部视觉样式和响应式布局。
- `js/main.js`：筛选、灯箱、动画和可视化编辑器。
- `works/`：各个重点项目的案例页。
- `assets/img/`：网站实际使用的精选图片。
- `作品图/`：原始作品资料，不会被网站编辑器覆盖。
